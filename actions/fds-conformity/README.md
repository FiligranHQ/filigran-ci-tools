# FDS Conformity Action

Runs the Filigran design-system (FDS) conformity check a product carries in
`fds-migration/scripts/check-fds-conformity.mjs`, generated by
`pnpm generate:fds-migration --product <name>` in the filigran-design-system repo.

## Usage

```yaml
steps:
  - uses: actions/checkout@v7
  - uses: actions/setup-node@v7
    with:
      node-version: '24'
  - name: FDS conformity
    uses: FiligranHQ/filigran-ci-tools/actions/fds-conformity@main
```

## Notes
- Runs from the repository root, which must contain `fds-migration/`.
- Node must already be on the `PATH`; the script has no dependencies.
- Install the front-end dependencies first to have `bridge-freshness` computed
  against the installed `@filigran/design-system`; without them it reports SKIPPED.
