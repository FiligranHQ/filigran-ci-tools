# FDS MUI Regression Action

Runs the MUI regression gate a product carries in
`fds-migration/scripts/check-mui-regression.mjs`. It fails when a pull request
adds an import of a MUI component the design system already replaces in that
product, as listed in `fds-migration/mui-regression-policy.generated.json`
(generated by `pnpm generate:mui-regression-policy --product <name>` in the
filigran-design-system repo). The policy in force is printed afterwards, pass or fail.

## Usage

```yaml
on: pull_request
steps:
  - uses: actions/checkout@v7
  - uses: actions/setup-node@v7
    with:
      node-version: '24'
  - name: FDS MUI regression
    uses: FiligranHQ/filigran-ci-tools/actions/fds-mui-regression@main
```

### Inputs
- `base-ref`: (optional) Branch to diff against. Default: `github.base_ref`, so
  outside a `pull_request` event it must be set.

## Notes
- Runs from the repository root, which must contain `fds-migration/`.
- Node must already be on the `PATH`; the script has no dependencies.
- Works with a shallow checkout: the action fetches the base branch and
  unshallows the clone itself.
